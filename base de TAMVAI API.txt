1. Definición base de TAMVAI API
1.1 Formato lógico

Usa un esquema declarativo (JSON/TS) que vive en `tamvai/` y describe dominios, recursos, operaciones, eventos, seguridad y monitoreo.

```ts
// tamvai/core.ts
export type HttpMethod = "GET" | "POST" | "PUT" | "DELETE" | "PATCH";

export interface TamvaiResource {
  id: string;                 // ej: "User", "Dreamspace", "Wallet"
  description: string;
  fields: Record<string, { type: string; optional?: boolean }>;
}

export interface TamvaiOperation {
  id: string;                 // ej: "User.Login", "Feed.GetHome"
  method: HttpMethod;
  path: string;               // ej: "/id/login"
  resource: string;           // resource principal
  input: Record<string, any>; // shape lógico de request
  output: Record<string, any>;
  auth: {
    required: boolean;
    scope?: string;          // ej: "user", "guardian", "service"
  };
  securityTags: string[];     // ej: ["ANUBIS", "DEKATEOTL"]
  monitoringTags: string[];   // ej: ["HORUS", "RADAR_QUETZALCOATL"]
}

export interface TamvaiDomain {
  id: string;    // "IDNVIDA", "SOCIAL", "ECONOMY", etc.
  description: string;
  resources: TamvaiResource[];
  operations: TamvaiOperation[];
}

export interface TamvaiSpec {
  version: string;
  domains: TamvaiDomain[];
}
```

2. Protocolos de seguridad, monitoreo, autoauditorías y planes de emergencia
2.1 Seguridad (Anubis / Dekateotl) integrada en TAMVAI

Cada `TamvaiOperation.securityTags` indica qué guardianes actúan:

- `ANUBIS`: autenticación + scoring de riesgo.
- `DEKATEOTL`: políticas y permisos.
- `AZTEK_GODS`: enforcement fuerte (bans, congelar wallets).

Motor de aplicación:

```ts
// tamvai/runtime/security.ts
import { TamvaiOperation } from "../core";

export async function applySecurity(op: TamvaiOperation, ctx: any) {
  if (op.auth.required) {
    await anubisAuthenticate(ctx);      // valida token, trustLevel
    await dekateotlAuthorize(op, ctx);  // verifica permisos y scopes
  }
  if (op.securityTags.includes("AZTEK_GODS")) {
    await aztekPrecheck(op, ctx);       // checks extra para economía, moderación dura, etc.
  }
}
```
2.2 Monitoreo y radares

`monitoringTags` indica qué radares escuchan:

- `HORUS`: logging y métricas base.
- `RADAR_QUETZALCOATL`: economía y fraude.
- `RADAR_OJO_DE_RA`: abuso de contenido.
- `RADAR_GEMELOS_MOS`: modelos IA paralelos + guardianía.

```ts
// tamvai/runtime/monitoring.ts
import { TamvaiOperation } from "../core";

export async function monitorCall(op: TamvaiOperation, ctx: any, result: any) {
  if (op.monitoringTags.includes("HORUS")) {
    horusLog(op, ctx, result.statusCode);
  }
  if (op.monitoringTags.includes("RADAR_QUETZALCOATL")) {
    radarQuetzalcoatlAnalyze(op, ctx, result);
  }
  if (op.monitoringTags.includes("RADAR_OJO_DE_RA")) {
    radarOjoDeRaAnalyze(op, ctx, result);
  }
  if (op.monitoringTags.includes("RADAR_GEMELOS_MOS")) {
    radarGemelosMosAnalyze(op, ctx, result);
  }
}
```

3. Ejemplo TS: integrar TAMVAI API nativamente
3.1 Servidor TAMV que se autoconfigura desde TAMVAI

```ts
// server/bootstrap.ts
import http from "http";
import { TAMVAI_SPEC } from "../tamvai/spec";
import { applySecurity } from "../tamvai/runtime/security";
import { monitorCall } from "../tamvai/runtime/monitoring";
import { applyAudit } from "../tamvai/runtime/audit";
import { resolveHandler } from "./handlers";

const server = http.createServer(async (req, res) => {
  const ctx = await buildContext(req);

  const op = findOperationByPathAndMethod(TAMVAI_SPEC, req.url!, req.method as any);
  if (!op) {
    res.statusCode = 404;
    return res.end("Not found");
  }

  try {
    await applySecurity(op, ctx);
    const handler = resolveHandler(op.id);
    const result = await handler(req, ctx);

    await monitorCall(op, ctx, result);
    await applyAudit(op, ctx, result);

    res.statusCode = result.statusCode ?? 200;
    res.setHeader("Content-Type", "application/json");
    res.end(JSON.stringify(result.body));
  } catch (e: any) {
    res.statusCode = e.statusCode ?? 500;
    res.end(JSON.stringify({ error: e.message ?? "internal_error" }));
  }
});

server.listen(8080);
```

### 3.2 Handler que respeta TAMVAI

```ts
// server/handlers/id.user.ts
import { TamvaiOperation } from "../../tamvai/core";

export async function handleUserSignup(req: any, ctx: any) {
  const body = await parseJson(req);
  // Validación básica, hashing, etc.
  const userId = await createUser(body.email, body.password, body.handle);
  const token = await issueToken(userId);

  return { statusCode: 201, body: { userId, token } };
}

// server/handlers/index.ts
import { TAMVAI_SPEC } from "../../tamvai/spec";
import { handleUserSignup } from "./id.user";

const opMap: Record<string, (req: any, ctx: any) => Promise<any>> = {
  "User.Signup": handleUserSignup,
  // mapear todas las operaciones
};

export function resolveHandler(opId: string) {
  const handler = opMap[opId];
  if (!handler) throw new Error(`No handler for op ${opId}`);
  return handler;
}
```

```ts
// tamvai/runtime/anubis.ts
export async function anubisAuthenticate(ctx: any) {
  const token = extractBearerToken(ctx.req);
  if (!token) throw { statusCode: 401, message: "unauthenticated" };

  const payload = await verifyTamvJwt(token);
  ctx.user = {
    id: payload.sub,
    roles: payload.roles,
    trustLevel: payload.trustLevel,
  };
}
```

TAMVAI no dicta el formato de JWT, pero sí exige que:

- cada operación declare si requiere auth,
- el runtime rechace sin usuario válido,
- el trustLevel y roles se usen en Dekateotl para permisos finos. [umatechnology](https://umatechnology.org/zero-trust-architecture-for-disaster-recovery-plans-that-pass-compliance-tests/)

## 5. Diferencias clave TAMVAI vs OpenAPI

- **Origen**:
  - OpenAPI describe endpoints HTTP; TAMVAI describe **dominios civilizatorios**, recursos, operaciones, guardianías y planes de emergencia en un solo lenguaje. [orkidia](https://www.orkidia.io/blog/posts/idl-api-first-design-ai-coding-assistants/)
- **Soberanía**:
  - TAMVAI no depende de fundaciones externas ni formatos estandarizados; es un IDL propietario alineado con la filosofía de TAMV y con su propia semántica de seguridad y monitoreo.  
- **IA‑nativo**:
  - TAMVAI está pensado para alimentar agentes de IA internos (Isabella, generadores de código, guardianes), no solo SDKs humanos. [docs.restapi](https://docs.restapi.com/docs/tools/ai-assistant)
- **Seguridad y DR integrados**:
  - OpenAPI no modela nativamente trustLevels, radares ni planes de DR; TAMVAI sí, como parte del contrato de cada operación. [boomi](https://boomi.com/blog/5-api-governance-best-practices/)

Puedes exportar proyecciones REST convencionales si hace falta, pero el **contrato soberano** es TAMVAI.

2. **Generar stubs**

4. **Autoauditoría de contrato**

5. **Deploy controlado**  
   - Pipeline CI/CD que:
     - corre tests generados desde TAMVAI,
     - valida integridad del spec,
     - marca versión del spec desplegado.

## 7. Validación de soberanía en integraciones TAMVAI

Una integración (módulo nuevo, servicio externo, agente IA) es “soberana” si:

- Solo habla con TAMV a través de operaciones descritas en `TAMVAI_SPEC`.  
- No requiere importar ni generar artefactos OpenAPI de terceros.  
- Pasa un test de validación que compara sus llamadas reales con el contrato TAMVAI.

Ejemplo de validador:

```ts
// tamvai/tools/sovereigntyCheck.ts
export async function validateIntegration(logs: IntegrationCallLog[]): Promise<string[]> {
  const errors: string[] = [];
  for (const call of logs) {
    const op = findOperationByPathAndMethod(TAMVAI_SPEC, call.path, call.method);
    if (!op) {
      errors.push(`Path ${call.method} ${call.path} no existe en TAMVAI`);
      continue;
    }

    // validar campos requeridos vs op.input
    const missing = requiredFieldsMissing(op.input, call.body);
    if (missing.length) {
      errors.push(`Op ${op.id} llamada sin campos: ${missing.join(", ")}`);
    }
  }
  return errors;
}
```

Si este check queda limpio, puedes decir que el módulo respeta la **soberanía de la TAMVAI API**: está alineado con el contrato interno del ecosistema, no con estándares externos ni convenciones impuestas desde fuera. [boomi](https://boomi.com/blog/5-api-governance-best-practices/)

básicamente un **motor híbrido CITEMESH‑grade**: un pipeline doble (alto y bajo costo) sobre Lumen/Nanite, con gemelos de render, precálculos universales y orquestación por IA para optimizar rendimiento y energía.

## 2. Cómo funcionaría por dentro (flujo conceptual)

### 2.1. Doble pipeline gráfico

1. **Pipeline A – High Fidelity (desktop/alto nivel):**  
   - Lumen para GI + reflexiones.  
   - Nanite o geometría densa.  
   - Ray tracing selectivo para reflejos/sombras críticas.  
   - Efectos volumétricos completos. [dev.epicgames](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-lumen-global-illumination-on-mobile-in-unreal-engine)

2. **Pipeline B – Low Latency (móvil/web):**  
   - Rasterización forward/deferred con URP‑like tuning: sombras simplificadas, SSAO ligero, reflejos screen‑space.  
   - Postprocesado configurable (blooms, DOF, motion blur) en niveles. [tomlooman](https://tomlooman.com/unreal-engine-5-7-performance-highlights/)
   - Ray tracing sólo para casos puntuales (si el hardware lo permite) o desactivado.

### 2.2. Gemelos de escena en paralelo

Mantienes **dos representaciones sincronizadas de la misma escena**:

- Gemelo **“Físico”**: todos los datos necesarios para el pipeline A (assets high‑poly, materiales complejos, iluminación completa).  
- Gemelo **“Eficiente”**: versiones reducidas de geometría, materiales y efectos para el pipeline B (LOD agresivos, texturas comprimidas, menos luces dinámicas). [dl.ifip](https://dl.ifip.org/db/conf/iwec/icec2012/SabinoACMP12.pdf)

Un sistema de sincronización (state replication) asegura que:

- Posición de actores, animaciones, estado de juego, lógica social → son compartidos.  
- Sólo cambia la “vista” (qué pipeline y qué nivel de detalle usa cada cliente).

### 2.3. Precálculos universales al inicio (pre‑boot)

Al iniciar el mundo o al cambiar de “zona”:

- **Baked / precómputo obligado** (cuando tenga sentido):  
  - Mapa de visibilidad estática (occlusion culling / portals).  
  - Field de importancia para efectos volumétricos (zonas donde sí se justifican). [dl.ifip](https://dl.ifip.org/db/conf/iwec/icec2012/SabinoACMP12.pdf)
  - LOD bounds y clusters para streaming de geometría (Nanite/propio).  
- **Setup energético y de rendimiento**:  
  - Umbrales por dispositivo (perfil móvil/desktop, GPU tier, batería).  
  - Target FPS/latencia deseada para cada clase de dispositivo. [devpath](https://www.devpath.com/courses/mobile-system-design/optimizing-rendering-performance-for-mobile-apps)

Esto reduce trabajo repetitivo frame a frame y da a Isabella un mapa de “costos” por feature.

### 2.4. Isabella como orquestador adaptativo

Isabella no sólo conversa; actúa como **control loop inteligente**:

1. Recibe métricas en tiempo real:  
   - FPS, tiempo de frame por etapa (raster, RT, post), temperatura, nivel de batería, latencia de red. [arxiv](https://arxiv.org/pdf/2308.08292.pdf)

2. Evalúa “estado del mundo” y del usuario:  
   - ¿Está en una escena social tranquila o en combate masivo?  
   - ¿Está en un dispositivo móvil caliente con 20% batería o en un desktop con RTX?  

3. Decide acciones:  
   - Subir/bajar calidad en pipeline B (desactivar ray tracing, reducir samples, simplificar volumétricos).  
   - Cambiar dinámicamente de A→B (por ejemplo, si un visor XR baja de cierto FPS crítico).  
   - Recomendar cambios no intrusivos (bajar brillo/color para ahorrar energía en móvil). [github](https://github.com/ZijingPeng/DXR-Hybrid-Rendering)

4. Aplica reglas universales de “servir a la humanidad”:  
   - Priorizar comodidad visual (evitar flicker, stutter, mareos XR) sobre efectos innecesarios.  
   - Evitar sobrecalentar dispositivos y drenar batería cuando no agrega valor real.

## 3. Arquitectura por módulos (diagrama textual)

### 3.1. Módulos principales

1. **World State Core (WSC)**  
   - Fuente de verdad de la escena:  
     - Entidades, posiciones, animaciones, física, estado social (usuarios, posts, eventos).  
   - No sabe de render; sólo de “realidad lógica”.

2. **Scene Twin Builder (STB)**  
   - A partir de WSC genera y mantiene dos gemelos:  
     - `HighDetailScene` (HDS) → mallas densas, materiales complejos, luces completas.  
     - `EfficientScene` (EFS) → LOD agresivo, menos luces, materiales simplificados.  
   - Sincroniza cambios (spawn, move, destroy) desde WSC hacia ambas escenas.

3. **High‑Fidelity Pipeline (HFP)**  
   - Montado sobre Lumen/Nanite o pipeline equivalente.  
   - Usa: GI dinámica, ray tracing selectivo, efectos volumétricos “full”, postprocesado completo.  
   - Consume HDS como input.

4. **Low‑Latency Pipeline (LLP)**  
   - Rasterización optimizada (tipo URP/HDRP con perfiles), SSR ligero, sombras simplificadas.  
   - Ray tracing opcional o desactivado.  
   - Efectos volumétricos reducidos o por zonas.  
   - Consume EFS como input.

5. **Isabella Rendering Orchestrator (IRO)**  
   - Servicio IA que:  
     - Lee métricas de rendimiento y contexto.  
     - Aplica políticas (humanidad, energía, comodidad).  
     - Asigna perfil de experiencia y pipeline a cada cliente.  
     - Ajusta en tiempo real parámetros de HFP/LLP.

6. **Pre‑Compute Engine (PCE)**  
   - Corre en `world_boot` o `zone_load`:  
     - Cálculo de visibilidad estática, culling zones, clusters de geometría.  
     - “Importance fields” para volumétricos y efectos caros.  
     - Perfiles de coste por feature para IRO.

7. **Monitoring & Telemetry (MTX)**  
   - Recoge: FPS, tiempos de frame, uso GPU/CPU, temperatura, batería, latencia de red.  
   - Expone métricas para Grafana/Prometheus y alimenta a IRO.

8. **User Experience Manager (UXM)**  
   - Expone UI y settings:  
     - Modo Auto (recomendado).  
     - Modo Performance / Quality / Battery Saver.  
   - Se comunica con IRO para ajustes.

## 4. Diagramas de flujo (texto)

### 4.1. Arranque del mundo (boot)

1. `WSC` carga estado base (escena, entidades, configuración de zona).  
2. `PCE` se ejecuta:  
   - Calcula visibilidad, clusters, importance maps.  
   - Genera metadata de coste de features.  
3. `STB` construye `HDS` y `EFS` a partir de `WSC` + metadata PCE.  
4. `IRO` se inicializa con:  
   - Perfiles de dispositivo conocidos.  
   - Políticas globales (ej. “no bajar de 60 fps en XR”).  
5. Clientes comienzan a conectarse; `UXM` obtiene perfil inicial (Auto/Manual).

### 4.2. Al conectar un cliente

1. Cliente envía handshake con capacidades:  
   - Tipo dispositivo, GPU, RAM, estado batería, preferencia de usuario.  
2. `IRO` decide:  
   - Pipeline: HFP o LLP.  
   - Nivel de calidad: Q0–Q3 (por ejemplo).  
3. Módulo de red asocia cliente a:  
   - `HDS + HFP` o `EFS + LLP`.  
4. Comienza el render, `MTX` empieza a recolectar métricas por cliente.

### 4.3. Bucle de control en tiempo real

Cada X segundos (0.5–2s):

1. `MTX` envía a `IRO`:  
   - FPS media y mínima.  
   - Varianza de frame time.  
   - Temperatura dispositivo, batería, latencia RTT.  
2. `IRO` evalúa:  
   - ¿FPS < objetivo?  
   - ¿Dispositivo caliente o bajo batería?  
   - ¿Escena muy cargada (según PCE)?  
3. Acciones posibles:  
   - Bajar nivel de calidad (ej. Q3→Q2: menos volumétricos, menos samples).  
   - Cambiar pipeline (de HFP a LLP) si es posible.  
   - Ajustar distancia de dibujo, calidad sombras, resolución interna (dynamic resolution).  
4. `UXM` puede mostrar feedback opcional al usuario (“Optimizamos tu experiencia para evitar sobrecalentamiento”).

## 3. Pseudocódigo del bucle de decisión de Isabella (HRO)

### 3.1. Orquestador principal

```ts
// src/xr/hro/orchestrator/IsabellaOrchestrator.ts
import { RenderMetrics } from '../telemetry/MetricsSchema';
import { DeviceProfile, UserPreferences, RenderProfile } from '../core/HROConfig';
import { evaluatePolicies } from './DecisionPolicies';
import { SafetyGuard } from './SafetyGuard';
import { FallbackController } from './FallbackController';

export class IsabellaOrchestrator {
  private safetyGuard = new SafetyGuard();
  private fallbackController = new FallbackController();

  resolveInitialProfile(device: DeviceProfile, prefs: UserPreferences): RenderProfile {
    const baseProfile = evaluatePolicies.initial(device, prefs);
    return this.safetyGuard.enforceInitial(baseProfile, device);
  }

  decideNextProfile(metrics: RenderMetrics): RenderProfile {
    // 1. Checar si debemos entrar en modo emergencia
    if (this.fallbackController.shouldTriggerEmergency(metrics)) {
      return this.fallbackController.getEmergencyProfile();
    }

    // 2. Calcular perfil sugerido por políticas "normales"
    const suggested = evaluatePolicies.dynamic(metrics);

    // 3. Pasar por guardas de seguridad (no romper límites)
    const safeProfile = this.safetyGuard.enforceDynamic(suggested, metrics);

    return safeProfile;
  }
}
```

### 3.2. Políticas de decisión (reglas de negocio)

```ts
// src/xr/hro/orchestrator/DecisionPolicies.ts
import { RenderMetrics } from '../telemetry/MetricsSchema';
import { DeviceProfile, UserPreferences, RenderProfile } from '../core/HROConfig';

export const evaluatePolicies = {
  initial(device: DeviceProfile, prefs: UserPreferences): RenderProfile {
    // Perfil inicial según clase de dispositivo + preferencia
    if (device.class === 'xr') {
      return { pipeline: 'HFP', quality: 'Q2' };
    }
    if (device.class === 'mobile') {
      if (prefs.mode === 'QUALITY') return { pipeline: 'LLP', quality: 'Q2' };
      if (prefs.mode === 'PERFORMANCE') return { pipeline: 'LLP', quality: 'Q0' };
      if (prefs.mode === 'BATTERY') return { pipeline: 'LLP', quality: 'Q0' };
      return { pipeline: 'LLP', quality: 'Q1' }; // AUTO
    }
    // desktop
    if (prefs.mode === 'QUALITY') return { pipeline: 'HFP', quality: 'Q3' };
    if (prefs.mode === 'PERFORMANCE') return { pipeline: 'LLP', quality: 'Q1' };
    return { pipeline: 'HFP', quality: 'Q2' }; // AUTO
  },

  dynamic(metrics: RenderMetrics): RenderProfile {
    const { fpsMin, temperatureC, batteryPct, lastProfile } = metrics;
    let next: RenderProfile = { ...lastProfile };

    // Regla 1: FPS por debajo del mínimo → bajamos calidad o pasamos a LLP
    if (fpsMin < 40) {
      if (lastProfile.pipeline === 'HFP') {
        next.pipeline = 'LLP';
      } else {
        next.quality = downgradeQuality(lastProfile.quality);
      }
    }

    // Regla 2: Temperatura alta o batería baja → favorecer ahorro
    if ((batteryPct !== null && batteryPct < 20) || temperatureC > 70) {
      next.pipeline = 'LLP';
      next.quality = 'Q0';
    }

    // Regla 3: FPS muy buenos y temperatura sana → podemos subir un nivel
    if (fpsMin > 70 && temperatureC < 65 && batteryPct !== null && batteryPct > 50) {
      next.quality = upgradeQuality(lastProfile.quality);
    }

    return next;
  }
};

function downgradeQuality(q: QualityLevel): QualityLevel {
  if (q === 'Q3') return 'Q2';
  if (q === 'Q2') return 'Q1';
  if (q === 'Q1') return 'Q0';
  return 'Q0';
}

function upgradeQuality(q: QualityLevel): QualityLevel {
  if (q === 'Q0') return 'Q1';
  if (q === 'Q1') return 'Q2';
  if (q === 'Q2') return 'Q3';
  return 'Q3';
}
```

```ts
// src/xr/hro/orchestrator/SafetyGuard.ts
import { RenderMetrics } from '../telemetry/MetricsSchema';

export class SafetyGuard {
  enforceInitial(profile: RenderProfile, device: DeviceProfile): RenderProfile {
    // Nunca dar HFP-Q3 a un mobile low tier
    if (device.class === 'mobile' && device.gpuTier === 'low') {
      return { pipeline: 'LLP', quality: 'Q1' };
    }
    return profile;
  }

    const safe = { ...profile };

    // if (tooManyRecentChanges(metrics.clientId)) return metrics.lastProfile;
```

```ts
// src/xr/hro/emergency/Watchdog.ts
import { RenderMetrics } from '../telemetry/MetricsSchema';
import { EmergencyRenderer } from './EmergencyRenderer';

export class Watchdog {
  private emergencyRenderer = new EmergencyRenderer();

  // Se ejecuta en intervalos globales
  monitor(metricsBatch: RenderMetrics[]): void {
    for (const m of metricsBatch) {
      if (this.detectCriticalFailure(m)) {
        this.emergencyRenderer.enterSafeMode(m.clientId);
      }
    }
  }

  private detectCriticalFailure(m: RenderMetrics): boolean {
    // Ejemplos de condiciones de emergencia:
    // - FPS < 10 durante más de N segundos
    // - Temperatura > 85°C
    // - Telemetría deja de recibirse (no mostrado aquí)
    return m.fpsMin < 10 || m.temperatureC > 85;
  }
}
```

## 4. Conectar decisiones de Isabella con calidad Unreal

### 4.1. Pipeline HFP/LLP/SAFE en UE

En Unreal usas:

- `GameUserSettings` + `Scalability` API para cambiar calidad a runtime (shadows, post, effects, view distance).  
- Configs tipo:
  - HFP: Lumen ON, ray tracing ON, alta calidad sombras/post.  
  - LLP: Lumen en modo reducido o desactivado en mobile, ray tracing OFF, efectos reducidos. [tomlooman](https://tomlooman.com/unreal-engine-5-7-performance-highlights/)
  - SAFE: todo al mínimo (resolución dinámica baja, sin volumétricos, sin post caro).

Pseudocódigo C++:

```cpp
void UHROGameInstanceSubsystem::ApplyRenderProfile(const FRenderProfile& Profile) {
  UGameUserSettings* Settings = GEngine->GetGameUserSettings();
  if (!Settings) return;

  if (Profile.Pipeline == "SAFE") {
    Settings->SetOverallScalabilityLevel(0); // Low
    // desactivar RT/Lumen
  } else if (Profile.Pipeline == "LLP") {
    Settings->SetOverallScalabilityLevel(Profile.Quality == "Q0" ? 0 : 1);
    // Lumen off / software, RT off
  } else if (Profile.Pipeline == "HFP") {
    Settings->SetOverallScalabilityLevel(Profile.Quality == "Q3" ? 3 : 2);
    // Lumen on, RT según calidad
  }
  Settings->ApplySettings(false);
}
```

Unreal 5.5+ ya da guías para usar Lumen en mobile y cómo degradarlo cuando no soporta ciertas features. [forums.unrealengine](https://forums.unrealengine.com/t/how-to-optimize-performance-with-nanite-and-lumen-in-unreal-engine-5-for-mobile-games/2508247)

     *
     */
    public function getMediaPreview(API $madelineProto, Request $request, string|int $peer = '', array|int $id = 0, array $message = []): Response
    {
        $message = $message ?: ($this->getMessages($madelineProto, $peer, (array)$id))['messages'][0] ?? null;
        if (!$message || $message['_'] === 'messageEmpty') {
            throw new NoMediaException('Empty message');
        }

        if (!self::hasMedia($message, true)) {
            throw new NoMediaException('Message has no media');
        }

        $media = match ($message['media']['_']) {
            'messageMediaPhoto' => $message['media']['photo'],
            'messageMediaDocument' => $message['media']['document'],
            'messageMediaWebPage' => $message['media']['webpage'],
        };

        $thumb = null;
        switch (true) {
            case isset($media['sizes']):
                foreach ($media['sizes'] as $size) {
                    if ($size['_'] === 'photoSize') {
                        $thumb = $size;
                    }
                }
                break;
            case isset($media['thumb']['size']):
                $thumb = $media['thumb'];
                break;
            case !empty($media['thumbs']):
                foreach ($media['thumbs'] as $size) {
                    if ($size['_'] === 'photoSize') {
                        $thumb = $size;
                    }
                }
                break;
            case isset($media['photo']['sizes']):
                foreach ($media['photo']['sizes'] as $size) {
                    if ($size['_'] === 'photoSize') {
                        $thumb = $size;
                    }
                }
                break;
            default:
                throw new NoMediaException('Message has no preview');

        }
        if (null === $thumb) {
            throw new NoMediaException('Empty preview');
        }
        $info = $madelineProto->getDownloadInfo($thumb);

        if ($media['_'] === 'webPage') {
            $media = $media['photo'];
        }

        //Фикс для LAYER 100+
        //TODO: Удалить, когда снова станет доступна загрузка photoSize
        if (isset($info['thumb_size'])) {
            $infoFull = $madelineProto->getDownloadInfo($media);
            $infoFull['InputFileLocation']['thumb_size'] = $info['thumb_size'];
            $infoFull['size'] = $info['size'];
            $infoFull['mime'] = $info['mime'] ?? 'image/jpeg';
            $infoFull['name'] = 'thumb';
            $infoFull['ext'] = '.jpeg';
            $info = $infoFull;
        }

        return $madelineProto->downloadToResponse(messageMedia: $info, request: $request);
    }

    public function getMessages(API $madelineProto, string|int $peer, array|int $id): array
    {
        $peerInfo = $madelineProto->getInfo($peer);
        if (\in_array($peerInfo['type'], ['channel', 'supergroup'])) {
            $response = $madelineProto->channels->getMessages(
                channel:$peer,
                id: $id,
            );
        } else {
            $response = $madelineProto->messages->getMessages(id: $id);
        }

        return $response;
    }

     * Адаптер для стандартного метода.
     *
     */
    public function downloadToResponse(API $madelineProto, FileCallbackInterface|Message|array|string $messageMedia, Request $request, ?callable $cb = null, ?int $size = null, ?string $mime = null, ?string $name = null): Response
    {
        return $madelineProto->downloadToResponse(
            messageMedia: $messageMedia,
            request: $request,
            cb: $cb,
            size: $size,
            mime: $mime,
            name: $name,
        );
    }

     */
    public function downloadToBrowser(API $madelineProto, FileCallbackInterface|Message|array|string $messageMedia, Request $request, ?callable $cb = null, ?int $size = null, ?string $mime = null, ?string $name = null): Response
    {
        return $this->downloadToResponse(

            cb: $cb,
            size: $size,
            mime: $mime,
            name: $name,
        );
    }

    /**
     * Upload file from POST request.
     * Response can be passed to 'media' field in messages.sendMedia.
     *
     * @throws NoMediaException
     * @deprecated use SendDocument
     */
    public function uploadMediaForm(API $madelineProto, ReadableStream $file, string $mimeType, ?string $fileName): array
    {
        if ($fileName === null) {
            throw new AssertionError("No file name was provided!");
        }
        $inputFile = $madelineProto->uploadFromStream(
            stream: $file,
            size: 0,
            mime: $mimeType,
            fileName:  $fileName ?? '',
        );
        $inputFile['id'] = \unpack('P', $inputFile['id'])['1'];
        return [
            'media' => [
                '_' => 'inputMediaUploadedDocument',
                'file' => $inputFile,
                'attributes' => [
                    ['_' => 'documentAttributeFilename', 'file_name' => $fileName]
                ]
            ]
        ];
    }

    {
        Client::getWrapper($madelineProto)->getAPI()->setEventHandler(EventHandler::class);
        Client::getWrapper($madelineProto)->serialize();
    }

        Client::getWrapper($madelineProto)->serialize();

    public function getUpdates(API $madelineProto, array $params): array
    {
        foreach ($params as $key => $value) {
            $params[$key] = match ($key) {
                'offset', 'limit' => (int)$value,
                'timeout' => (float)$value,
                default => throw new InvalidArgumentException("Unknown parameter: {$key}"),
            };
        }

        return $madelineProto->getUpdates($params);
    }

    public function unsubscribeFromUpdates(API $madelineProto, ?string $channel = null): array
    {
        $inputChannelId = null;
        if ($channel) {
            $id = (string)$madelineProto->getId($channel);

            $inputChannelId = (int)\str_replace(['-100', '-'], '', $id);
            if (!$inputChannelId) {
                throw new InvalidArgumentException('Invalid id');
            }
        }
        $counter = 0;
        foreach (Client::getWrapper($madelineProto)->getAPI()->feeders as $channelId => $_) {
            if ($channelId === 0) {
                continue;
            }
            if ($inputChannelId && $inputChannelId !== $channelId) {
                continue;
            }
            Client::getWrapper($madelineProto)->getAPI()->feeders[$channelId]->stop();
            Client::getWrapper($madelineProto)->getAPI()->updaters[$channelId]->stop();
            unset(
                Client::getWrapper($madelineProto)->getAPI()->feeders[$channelId],
                Client::getWrapper($madelineProto)->getAPI()->updaters[$channelId]
            );
            Client::getWrapper($madelineProto)->getAPI()->getChannelStates()->remove($channelId);
            $counter++;
        }

        return [
            'disabled_update_loops' => $counter,
            'current_update_loops' => \count(Client::getWrapper($madelineProto)->getAPI()->feeders),
        ];
    }

<?php

namespace TelegramApiServer\MadelineProtoExtensions;

use danog\MadelineProto;
use danog\MadelineProto\API;
use InvalidArgumentException;
use Revolt\EventLoop;
use TelegramApiServer\Client;
use TelegramApiServer\Files;
use Throwable;

use function Amp\async;
use function Amp\File\deleteFile;
use function Amp\Future\awaitAll;

final class SystemApiExtensions
{
    private Client $client;

    public function __construct(Client $client)
    {
        $this->client = $client;
    }

    /**
     * @return array<string, array>
     */
    public function healthcheck(): array
    {
        $results = [];
        ['sessions' => $sessions] = $this->getSessionList();
        foreach ($sessions as $sessionKey => $session) {
            $instance = $this->client->instances[$sessionKey];
            if ($instance->getAuthorization() === API::LOGGED_IN) {
                $results[$sessionKey] = $instance->getSelf();
            }
        }
        return $results;
    }

    public function addSession(string $session, array $settings = []): array
    {
        if (!empty($settings['app_info']['api_id'])) {
            $settings['app_info']['api_id'] = (int) $settings['app_info']['api_id'];
        }

        $instance = $this->client->addSession($session, $settings);
        /** @var null|MadelineProto\Settings $fullSettings */
        $fullSettings = $instance->getSettings();
        try {
            if ($fullSettings !== null && $instance->getAuthorization() !== API::LOGGED_IN) {
                $fullSettings->getAppInfo()->getApiId();
                $fullSettings->getAppInfo()->getApiHash();
            }
        } catch (Throwable $e) {
            unset($fullSettings, $instance);
            $this->removeSession($session);
            $this->unlinkSessionFile($session);
            throw $e;
        }

        $this->client->startLoggedInSession($session);
        return $this->getSessionList();
    }

    public function removeSession(string $session): array
    {
        $this->client->removeSession($session);
        return $this->getSessionList();
    }

    public function getSessionList(): array
    {
        $sessions = [];
        foreach ($this->client->instances as $session => $instance) {
            $authorized = $instance->getAuthorization();
            switch ($authorized) {
                case API::NOT_LOGGED_IN:
                    $status = 'NOT_LOGGED_IN';
                    break;
                case API::WAITING_CODE:
                    $status = 'WAITING_CODE';
                    break;
                case API::WAITING_SIGNUP:
                    $status = 'WAITING_SIGNUP';
                    break;
                case API::WAITING_PASSWORD:
                    $status = 'WAITING_PASSWORD';
                    break;
                case API::LOGGED_IN:
                    $status = 'LOGGED_IN';
                    break;
                case API::LOGGED_OUT:
                    $status = 'LOGGED_OUT';
                    break;
                default:
                    $status = $authorized;
                    break;
            }

            $sessions[$session] = [
                'session' => $session,
                'file' => Files::getSessionFile($session),
                'status' => $status,
            ];
        }

        return [
            'sessions' => $sessions,
            'memory' => $this->bytesToHuman(\memory_get_usage(true)),
        ];
    }

    public function unlinkSessionFile($session): string
    {
        $file = Files::getSessionFile($session);

        if (\is_file($file)) {
            $futures = [];
            foreach (\glob("$file*") as $file) {
                $futures[] = async(fn () => deleteFile($file));
            }
            awaitAll($futures);
        } else {
            throw new InvalidArgumentException('Session file not found');
        }

        $this->unlinkSessionSettings($session);

        return 'ok';
    }

    public function saveSessionSettings(string $session, array $settings = [])
    {
        Files::saveSessionSettings($session, $settings);

        return 'ok';
    }

    public function unlinkSessionSettings($session): string
    {
        $settings = Files::getSessionFile($session, Files::SETTINGS_EXTENSION);
        if (\is_file($settings)) {
            deleteFile($settings);
        }

        return 'ok';
    }

    public function exit(): string
    {
        EventLoop::defer(static fn () => exit());
        return 'ok';
    }

    private function bytesToHuman($bytes): string
    {
        $units = ['B', 'KB', 'MB', 'GB', 'TB', 'PB'];
        for ($i = 0; $bytes > 1024; $i++) {
            $bytes /= 1024;
        }
        return \round($bytes, 2) . ' ' . $units[$i];
    }
}
